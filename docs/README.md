## Documentation boundaries

The user guide describes the published base. R2 documents planned work; it does not make that work available. Live discovery, current permissions, native feature flags and supported execution profiles determine what a connection can do.

Factory, WordPress and Google Analytics remain excluded. GSC is Google Search Console. Research batches are a separate research workflow, not Factory execution.
