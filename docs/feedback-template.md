Include the preview's expiry, declared work limits and known/unknown cost. For approval failures, record the status actually shown by the action page and the unchanged preview replay; signing in or approving an OAuth connection is not action approval. A missing correlation ID is useful evidence too: do not invent one. A screenshot of the status area is optional after redaction.

Record the specific action's quota separately from allowances for other actions. Do not repeat paid work or create replacement previews merely to improve a bug report. If a response is ambiguous, preserve the original IDs and last observed state.
