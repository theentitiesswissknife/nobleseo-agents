# NobleSEO 0.3.0 base release

This release packages the verified base guidance and local chart scripts. It does not deploy the NobleSEO backend, register OAuth clients, extend existing grants, activate native flags or perform provider work. The connected server's discovery, permissions, feature flags and qualified execution profiles remain authoritative.

## Included base workflows

- Keyword clustering, persisted research and briefs, and explicitly approved research workflows with original receipts and human checkpoints.
- Google Search Console reads, reports and local charts. Stored snapshots and exports remain separate from synchronization or a live Google connection.
- Supported single-article generation and canonical Refresh paths, including the qualified project-knowledge composition. Extra analysis/provider/media options are not implied by a native options list.
- Saved draft inspection, scoring, requested versioned changes, outline workflows and existing stored asset operations.
- Already qualified scoped link inspection, business review, simulation and exact draft insertion. This is not the complete Link Workbench expansion.
- Already qualified social derivative generation and document/task or reviewed social-delivery workflows, only when separately discovered and explicitly approved. These do not constitute Social Intelligence analytics.

## Deferred

Factory, WordPress and Google Analytics are outside this release. The Factory and WordPress skills are archived outside the installable plugin. Research batches retain their own research owner and guidance; they are not Factory execution.

Advanced generation/editor combinations, the remaining Link Workbench operations and Social Intelligence are reserved for the next implementation session. Existing partial/degraded/unknown receipts remain visible; unsupported features must not be replaced by another workflow or enabled silently.

## Compatibility and acceptance

Installing or updating this plugin alone cannot add backend tools or fix a backend approval failure. If a tool or scope is absent, retain the discovered limitation and use a permitted export/local-review fallback where appropriate. Do not claim that reconnecting or reinstalling repaired an approval.

Local backend protocol/domain tests, plugin repository checks, GitHub CI, backend deployment, installed-client testing and live provider acceptance are distinct evidence. This release makes no live/provider or installed-client acceptance claim from local tests. No backend Labs deployment accompanies this skill publication.
